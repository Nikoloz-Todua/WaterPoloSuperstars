# Water Polo Superstars — Codex Instructions

## Project
- Game: Water Polo Superstars
- Studio: ToduStudios
- Engine: Unity 6
- Render Pipeline: URP
- Primary platform: Android
- Secondary platform: iOS

## Main Rules
- Read `plan.md` before making significant changes.
- Do not delete or replace major systems without explaining why.
- Prefer simple, maintainable C# architecture.
- Keep mobile performance in mind.
- Do not modify unrelated files.
- Preserve Unity `.meta` files.
- Use Git checkpoints before large or risky changes.

## Documentation Rule
At the end of every meaningful development session:
1. Review what changed.
2. Update `plan.md` with the latest architecture, completed work, current state, and next steps.
3. Keep `plan.md` accurate enough that a new AI session can understand the project without relying on chat history.

Do not add temporary discussion, failed experiments, or irrelevant details to `plan.md`.
